✳ FORGE3D

A lightweight modeling workbench.

Describe an asset and Forge3D runs an eight-pass design workflow: prompt analysis, public reference research, cartoon concept, blockout, geometry audit, detail pass, clean rebuild and final QA. Optional Ollama uses a real local model to help write a bespoke blueprint. Geometry is assembled by a constrained low-poly modeling grammar, then exported as GLB, OBJ or a Roblox Lua starter rig.

01 / PromptName the silhouette, materials and proportions.
02 / InspectOrbit the model and check the triangle count.
03 / ExportDownload GLB, OBJ or the rig scaffold.

Important: the default engine is procedural and runs without a paid API. Optional Ollama adds real local model reasoning and image understanding, but does not magically train a new text-to-3D foundation model. High-fidelity neural mesh reconstruction requires a separate GPU inference backend.
